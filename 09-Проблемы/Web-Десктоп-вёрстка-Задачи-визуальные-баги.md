# Десктоп-версия страницы "Задачи" — визуальные проблемы (требуют живой отладки)

Три отдельные визуальные находки с реальных скриншотов `mindandmotion.ru`. В отличие от [[Web-Dashboard-отметка-выполнено-не-сохраняется]] и [[Web-Иконки-папок-в-модалке-задачи]], причину **не удалось надёжно установить чтением кода** — CSS выглядит на первый взгляд нормально, но фактический рендер расходится с ожиданием. Нужна живая сессия с devtools/Playwright (посмотреть computed styles, реальный DOM), не гадать по исходникам.

## 1. Много пустого пространства, вёрстка "так себе"

Субъективная, но обоснованная претензия — десктопная версия `/tasks` визуально бедная: узкая колонка контента, много пустого фона по краям. Нужен полноценный дизайн-проход по десктопному layout'у (возможно, стоит переосмыслить как двух-/трёхколоночную раскладку вместо растянутой одноколоночной), не точечный CSS-фикс.

## 2. Чекбокс отметки выполненности не виден

В коде чекбокс существует (`.task-checkbox`, `tasks.css:218-247` — 18×18px, `border: 2px solid var(--border-subtle)`, прозрачный фон) и должен рендериться слева от каждой карточки задачи. На скриншоте его не видно вообще перед заголовком задачи.

Гипотезы, не проверено:
- Реальный CSS-баг (например, элемент вообще не рендерится/схлопывается по какой-то причине).
- Просто визуально слишком тонкий/бледный на тёмном фоне при обычном масштабе экрана — не баг, а вопрос контраста.

Нужно открыть страницу вживую (или Playwright + zoom на конкретный элемент) и посмотреть, существует ли элемент в DOM и что показывают computed styles.

## 3. Модалка подзадач — текст наслаивается, нечитаемо

На скрине видно, что при открытии подзадач поверх карточки одновременно видны: всплывающий блок с текстом комментария, заголовок "Подзадачи · …", список подзадач — всё визуально наложено друг на друга, нечитаемо.

В коде (`TaskCard.tsx`, блок `{expanded && (...)}`, ~410-618) для десктопа используется `position: fixed; top: 50%; left: 50%; transform: translate(-50%, -50%)` с явным `zIndex: 201` и отдельным backdrop `zIndex: 200` — на бумаге должно центрироваться поверх всего с непрозрачным фоном. Возможные причины расхождения с реальным рендером: конфликт z-index с чем-то ещё на странице, не примененные стили из-за порядка CSS-файлов, либо десктопный код-путь на самом деле не срабатывает и рендерится мобильная (`isMobile`) ветка стилей на десктопном экране (проверить `window.innerWidth` в момент открытия).

## План на завтра

Открыть `/tasks` в браузере (или через Playwright с реальным логином, раз БД снова доступна), воспроизвести все три ситуации, посмотреть DOM/computed styles/консоль вживую — только после этого писать фикс, не наугад по исходникам.
