# Таймер для привычек-"Часы" искажает значение примерно в 60 раз

Классический для этого проекта класс бага (путаница часы/минуты в таймере привычек) — не решён на web, хотя на mobile решён правильно (суммирование, а не перезапись).

Цепочка перепутанных единиц:
- `web/src/components/HabitTable.tsx:308` передаёт текущее значение дня (оно **в часах** — так везде в остальном коде: `HoursEditModal.tsx:6`, `calculateHabitStats`) в проп с именем `existingMinutes`.
- `web/src/components/GlobalTimerBanner.tsx:90` (`getBaseSeconds()`) домножает это значение на 60, **трактуя его как минуты** — то есть часы × 60, интерпретированные как минуты × 60 = уже кратно неверно.
- При сохранении `getTotalMinutes()` (`GlobalTimerBanner.tsx:133-139`) возвращает число минут, которое напрямую пишется как новое значение дня (`HabitTable.tsx:309`) — а это поле везде читается как **часы**.

Итог: реально отработанный 1 час на привычке, где уже было 2 часа, запишется как ~62 (интерпретировано как 62 часа) вместо корректных 3.

Есть также мёртвый дубликат с той же ошибкой: `web/src/components/HabitTimerBanner.tsx` — не используется (в `Layout.tsx` подключён только `GlobalTimerBanner.tsx`), но может запутать при будущих правках.

## Что нужно

Минимальный безопасный фикс — привести к часам↔секундам последовательно на входе/выходе (`existingHours * 3600` на входе, `totalSeconds / 3600` с округлением на выходе), как уже сделано правильно на mobile (`HabitsScreen.js:812-829`, `HabitTable.js:120-134`). Удалить или синхронизировать неиспользуемый `HabitTimerBanner.tsx`.
