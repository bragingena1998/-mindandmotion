# Web/Задачи: сырая ошибка API показывается пользователю как есть

При сбое запроса на странице `/tasks` пользователь видит буквально `Request failed with status code 403` (или аналогичный текст ошибки Axios) — техническую строку на английском, без перевода и без кнопки повтора.

Скриншот (десктоп и мобильный) подтверждают: `Показывать выполненные` чекбокс отрисовывается нормально, а под ним просто красным текстом — сырое сообщение исключения.

## Для сравнения — как должно быть

Страница `/habits` в аналогичной ситуации показывает: "Ошибка загрузки привычек" + кнопка "Повторить" (см. `Habits.tsx`). Нужно привести `Tasks.tsx` к тому же паттерну — локализованный текст ошибки + retry.

## Как воспроизвести

Открыть `/tasks` с невалидным/просроченным токеном (или когда бэкенд/БД недоступны) — вместо дружелюбного состояния ошибки видно сырой `error.message` из Axios.
