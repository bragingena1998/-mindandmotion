# Повторение (рекуррентность) задач не работает

Владелец сообщил, что повтор задачи не срабатывает. Не до конца продиагностировано — нужна перепроверка завтра.

## Что уже проверено по коду

- `Tasks.tsx:handleToggleTask` (270-331) — логика выглядит корректной: вычисляет `nextDate` на фронте по `recurrenceType` (`daily`/`weekly`/`monthly`/`custom`) и передаёт полный набор полей задачи в `updateTask`.
- `backend/routes/tasks.js:343-401` (`PUT /:id`) — при `isRecurring && done && !oldTask.done` создаёт новую задачу на `nextDate`, копирует подзадачи. Логика на бэкенде тоже выглядит рабочей на чтение.

## Рабочая гипотеза

Владелец отмечал задачи выполненными **с дашборда** — см. [[Web-Dashboard-отметка-выполнено-не-сохраняется]]. Если это тот же случай, запрос падает с 500 ещё до того, как доходит до блока пересоздания рекуррентной задачи на бэкенде — тогда это не отдельный баг, а следствие первого.

## Что нужно сделать завтра

Перепроверить **именно через страницу "Задачи"** (не с дашборда): создать тестовую рекуррентную задачу, отметить выполненной чекбоксом на `/tasks`, проверить — появилась ли следующая задача на `nextDate`. Если появилась — баг был только в дашборде, эту заметку можно закрывать вместе с тем багом. Если не появилась — смотреть глубже (сетевые запросы, консоль, реальный ответ бэкенда).
