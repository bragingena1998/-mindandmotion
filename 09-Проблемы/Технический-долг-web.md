# Технический долг — Web

## Дублирование логики авторизации
`App.tsx` не использует `AuthContext.isAuthenticated` — держит собственный `useState`, читает токен из localStorage напрямую в `useEffect`. После `AuthContext.logout()` `App.tsx` не узнаёт об этом без перезагрузки страницы (кнопка "Выйти" в `Layout.tsx` вызывает `localStorage.removeItem` + `window.location.href` напрямую, минуя `useAuth().logout()`). Консолидировать на едином источнике правды — либо всё через контекст, либо убрать контекст и оставить как есть, но не оба одновременно.

## Токен не валидируется при монтировании
`AuthContext.tsx` содержит `// TODO: Validate token and get user info` — `user` остаётся `null` до логина в текущей сессии, нет проверки токена на бэкенде при старте приложения.

## Регистрация недоступна, но на неё есть рабочая ссылка
`Login.tsx` содержит ссылку "Зарегистрироваться", ведущую на `/register` — inline-заглушку без формы и без вызова API. Либо скрыть ссылку до реализации страницы, либо реализовать страницу.

## Двойной ключ токена
`client.ts` одновременно читает `app-auth-token` и `mm_token` — легаси-дублирование со времён миграции нейминга. Консолидировать на одном ключе.

## Отладочные console.log в проде
`Dashboard.tsx` — 3 явных `console.log('[Dashboard] …')`. `api/habits.ts` — 6 `console.log`, включая помеченные `// ДИАГНОСТИКА — удалить после проверки`. Убрать перед следующим релизом.

## Устаревший комментарий вводит в заблуждение
`Habits.tsx` (~строка 218): `// TODO: реальная модалка` над `handleModalSave`, хотя `HabitModal.tsx` уже реально делает `createHabit`/`updateHabit`. Комментарий не был убран после реализации — удалить.

## Рассинхрон порта дев-сервера в конфигах
`package.json` (`"dev": "vite --port 3001"`) против `vite.config.ts` (`port: 3002`). CLI-флаг побеждает (реальный порт — 3001), но лучше унифицировать явно в одном месте.

## Следы точечных патчей без чистки
Комментарии вида `// ФАЙЛ 2 FIX`, `// БАГ 5 FIX`, `// [4] ФИКС`, `// ШАГ 2` разбросаны по `Tasks.tsx` и `TaskModal.tsx` — стоит убрать при следующем рефакторинге этой области.
