# Владелец проекта — роль и контекст

**Кто:** единственный владелец и разработчик Mind & Motion (Геннадий/Gennadiy Bragin, Telegram @braginGA). Ведёт весь стек один — backend, mobile, web, landing — используя AI-ассистентов как основную рабочую силу для кода (раньше Perplexity как "мозг" + Windsurf как "руки", сейчас — Claude Code напрямую).

**Технический уровень:** уверенно ставит задачи и разбирается в архитектуре на уровне концепций, но не является профессиональным backend/infra-инженером — типичные проявления: путает пароль входа в phpMyAdmin с паролем пользователя MySQL, в прошлом переинициализировал git прямо на проде (потерял связь истории с GitHub), допускал случайный `git add` на `.env`. Не негативная характеристика — это нормально для соло-разработчика, дающая понимание, что инфраструктурные шаги стоит объяснять пошагово и перепроверять перед выполнением, а не считать самоочевидными.

**Платформа:** Windows, имя пользователя на кириллице (`Пользователь`) — это реальный источник багов (SSH не резолвит `~` для этого профиля, некоторые инструменты пишут файлы в UTF-16 вместо UTF-8 на этой машине). См. соответствующие уроки в `CLAUDE.md`.

**Как работает:** дома за ПК ("ноут дома, всё включено"), но хочет и умеет продолжать работу с телефона — тестировали и подтвердили, что Claude Code Remote Control это закрывает (двусторонний чат + кликабельные подтверждения с телефона).

**Продукт:** Mind & Motion — органайзер (задачи, привычки, календарь, фокус-сессии, дни рождения). Мобильное приложение уже в RuStore; в Apple App Store пока не публикует — по стоимости/усилиям, не потому что не готово. Сайт (`web/`) — вторая версия, целенаправленно догоняет мобильное приложение по функциям.

**Язык:** всё общение — только на русском, явно попросил в начале.
