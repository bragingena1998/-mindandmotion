# Шаблон: Запрос к Perplexity

> Стандартный промпт для отправки мне ([Perplexity](https://perplexity.ai)) после получения [INTAKE]-блока.
> Копируй полностью — не сокращай.

---

## Шаблон

```
Сделай Windsurf-ready prompt.

Вот intake:
[INTAKE]
<вставь блок сюда>
[/INTAKE]

Контекст проекта:
- Стек: React Native (mobile), React+Vite (web), Node.js+Express+MySQL (backend)
- ОС: Windows, PowerShell
- Windsurf + Cascade как executor

Нужно:
1. Краткий root-cause analysis (2-3 предложения)
2. Пошаговый план реализации
3. Точный prompt для Windsurf (готовый к вставке)
4. Что проверить после выполнения
```

---

## Когда добавлять дополнительный контекст

Если задача касается конкретного файла — добавь после блока:

```
Дополнительно:
- Файл: <путь к файлу>
- Текущее поведение: <что происходит>
- Ожидаемое: <что должно быть>
```
