# Mind & Motion — обзор

> Приложение-органайзер: задачи, привычки, календарь, фокус-сессии, дни рождения. Один владелец-разработчик + AI-агент (Claude Code) как со-пилот.

Этот vault — **единственный источник правды** по проекту. Ветка `docs/` в репозитории — архив (см. [[90-Архив/old-workflow/Индекс]]), `docs-v2/` свёрнут сюда же.

## Ключевые факты

- **API Base URL:** `https://mindandmotion.ru/api` (прод); локально порт бэкенда по умолчанию **3000** (не 5000 — старое расхождение, см. [[01-Backend/Текущее-состояние]]).
- **Auth:** JWT в `Authorization: Bearer`; web — localStorage, mobile — **AsyncStorage** (не SecureStore, вопреки старым правилам — см. [[02-Mobile/Текущее-состояние]]).
- **БД:** MySQL на VPS Beget, PM2-процесс `mindandmotion-backend`.
- **PowerShell only** на Windows (нет `&&`, пути в кавычках, диск `E:\`).
