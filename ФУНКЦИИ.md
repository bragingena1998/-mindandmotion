# MIND & MOTION — ФУНКЦИИ ПО ЭКРАНАМ

Документ содержит полный перечень всех экранов мобильного приложения Mind & Motion и их функционала.

## 1. DashboardScreen.js — Главный экран (Дашборд)

### Основное назначение
Главный экран приложения, показывающий сводку дня: приветствие, прогресс задач, активные привычки, события и дни рождения.

### Функции:

#### Данные и загрузка
- `useLocalFirst` — хук для local-first загрузки данных (мгновенная загрузка из кеша)
- `loadDashboard` — загрузка данных дашборда (профиль, задачи, привычки, записи привычек, дни рождения, папки)
- `refreshDashboard` — обновление данных дашборда
- `handleResetCache` — принудительный сброс кеша и перезагрузка данных

#### Вспомогательные функции дат
- `getGreeting()` — определение времени суток для приветствия (утро/день/вечер/ночь)
- `formatDateRu(date)` — форматирование даты на русском языке
- `isoToday()` — получение сегодняшней даты в формате ISO
- `isoTomorrow()` — получение завтрашней даты в формате ISO
- `parseHabitData(h)` — парсинг данных привычки (обработка days_of_week)
- `normPriority(p)` — нормализация приоритета задачи
- `normalizeTask(task)` — нормализация данных задачи
- `dateInRange(dayStr, task)` — проверка, находится ли день в диапазоне задачи
- `getTaskStatus(task)` — определение статуса задачи (today/overdue/future)
- `formatHabitCellValue(habit, v)` — форматирование значения ячейки привычки

#### Управление задачами
- `toggleTask(task)` — переключение статуса выполнения задачи (оптимистичное обновление)
- `formatTaskMeta(task)` — форматирование метаданных задачи (время, дедлайн)
- `AnimatedTaskCard` — компонент анимированной карточки задачи со свайпом
- `renderTaskCard(task, stripColor)` — рендер карточки задачи
- `loadTaskSubtasks(taskId)` — загрузка подзадач для задачи
- `openSubtasksModal(task)` — открытие модалки подзадач
- `toggleSubtaskInModal(subtaskId)` — переключение статуса подзадачи в модалке

#### Управление привычками
- `reloadHabitRecords()` — перезагрузка записей привычек
- `toggleHabit(habit)` — отметка выполнения привычки (оптимистичное обновление)
- `formatHabitCellValue(habit, v)` — форматирование значения привычки

#### События и прогресс
- `upcomingEvents` — вычисление ближайших событий (в пределах 7 дней)
- `progress` — расчет процента выполнения задач за день
- `allActiveDone` — проверка выполнения всех активных привычек

#### Фокус-сессия и таймер
- `focusTick` — таймер для обновления фокус-сессии
- `focus` / `focusTask` / `focusSeconds` — данные активной фокус-сессии
- `habitTimer` — таймер привычки с отслеживанием времени

## 2. LoginScreen.js — Экран входа

### Основное назначение
Экран авторизации пользователя с возможностью входа по email/пароль и смены темы.

### Функции:

#### Авторизация
- `handleLogin()` — обработка входа: валидация полей, запрос к API `/login`, сохранение токена
- `saveToken(token, userId)` — сохранение токена авторизации
- `saveUserEmail(email)` — сохранение email для автозаполнения

#### Темы оформления
- `cycleTheme()` — циклическое переключение тем (default/storm/ice/blood/toxic/glitch)
- `themes[]` — массив доступных тем с эмодзи
- `currentTheme` — текущая выбранная тема

#### Навигация
- `onNavigate('forgot-password')` — переход к восстановлению пароля
- `onNavigate('register')` — переход к регистрации
- `onLoginSuccess(user)` — успешный вход, переход в приложение

#### Дополнительные настройки

#### Навигация
- Переключение между шагами регистрации (step 1 / step 2)
- `onNavigate('login')` — переход к экрану входа

## 5. TasksScreen.js — Экран задач

### Основное назначение
Полноценный менеджер задач с папками, подзадачами, сортировкой, drag-and-drop и офлайн-режимом.

### Функции:

#### API задач
- `tasksAPI.getTasks(params)` — получение списка задач
- `tasksAPI.createTask(taskData)` — создание задачи
- `tasksAPI.updateTask(id, taskData)` — обновление задачи
- `tasksAPI.deleteTask(id)` — удаление задачи
- `tasksAPI.stopRecurring(id)` — остановка повторяющейся задачи
- `tasksAPI.addFocusSession(id)` — добавление фокус-сессии к задаче
- `tasksAPI.createTaskOffline` / `updateTaskOffline` / `deleteTaskOffline` — офлайн-версии с syncQueue

#### API папок
- `foldersAPI.getFolders()` — получение папок
- `foldersAPI.createFolder(data)` — создание папки
- `foldersAPI.updateFolder(id, data)` — обновление папки
- `foldersAPI.deleteFolder(id)` — удаление папки
- `foldersAPI.reorderFolders(folders)` — изменение порядка папок
- Офлайн-версии всех операций с папками

#### Загрузка и управление задачами
- `loadTasks(date, forceRefresh)` — загрузка задач с кешированием
- `checkOverdueTasks(allTasks)` — проверка просроченных задач старше недели
- `handleDeleteOldTasks()` — массовое удаление старых просроченных задач
- `onRefresh()` — pull-to-refresh обновление
- `toggleTask(taskId)` — переключение статуса задачи (оптимистичное обновление)
- `deleteTask(taskId)` — удаление задачи
- `stopRecurring(taskId)` — остановка повторений задачи

#### Подзадачи
- `loadSubtasks(taskId)` — загрузка подзадач
- `toggleExpand(taskId)` — развернуть/свернуть подзадачи
- `toggleSubtask(subtaskId, taskId)` — переключение статуса подзадачи
- `addSubtask()` — добавление новой подзадачи
- `deleteSubtask(subtaskId, taskId)` — удаление подзадачи
- `editSubtask(subtask, taskId)` — редактирование подзадачи

#### Папки
- `loadFolders()` — загрузка папок
- `handleCreateFolder()` — создание папки
- `handleUpdateFolder()` — обновление папки
- `handleDeleteFolder(folder)` — удаление папки
- `handleMoveFolderUp/Down(folder)` — перемещение папки вверх/вниз
- `getFolderById(id)` — получение папки по ID
- `handleFolderLongPress(folder)` — долгое нажатие на папку (меню действий)

#### Drag & Drop
- `onChipMeasure(fid, layout)` — измерение координат чипа папки
- `onLongPressStart(task, absX, absY)` — начало перетаскивания задачи
- `onPanGestureEvent` — обработка жеста перетаскивания
- `onPanStateChange` — завершение перетаскивания (отпускание задачи на папку)
- `FolderDropChip` — анимированный чип папки с эффектом наведения
- `DraggableTaskItem` — перетаскиваемая карточка задачи

#### Статистика
- `stats` — статистика задач (today, todayPlan, week, month, total)
- `countTodayPlanTotal(tasks)` — подсчет плана на сегодня
- `countCompletedToday(tasks)` — подсчет выполненных сегодня

#### Сортировка и фильтры
- `sortBy` — сортировка по дате/приоритету/названию
- `hideCompleted` — скрыть выполненные задачи
- `activeFolderId` — активная фильтр-папка

#### Фокус-сессии
- `handleFocusComplete(taskId)` — завершение фокус-сессии
- `FocusSessionModal` — модалка таймера концентрации
- `setFocusTask` / `setFocusVisible` — управление фокус-сессией

#### Туториал
- `useTutorial('tasks')` — хук туториала для задач
- `tutorialSteps[]` — шаги обучения (6 шагов)
- `startTutorial()` — запуск туториала
- `resetAllTutorials()` — сброс всех туториалов

#### Вспомогательные функции
- `normPriority(p)` — нормализация приоритета
- `toMysqlFormat(date)` — форматирование даты для MySQL
- `isoToday()` / `isoTomorrow()` — сегодня/завтра в ISO формате
- `debouncedSave(bumpFn, immediate)` — дебаунс для сохранения
- `showToast(msg)` — показ тоста
- `getTaskStatus(item)` — определение статуса задачи
- `formatTaskDate(item)` — форматирование даты задачи

## 6. HabitsScreen.js — Экран привычек

### Основное назначение

- `parseHabitData(h)` — парсинг данных привычки

#### Таблица привычек
- `HabitTable` — компонент таблицы привычек по дням месяца
- `handleCellChange(habitId, year, month, day, value)` — изменение значения ячейки
- `DaysSelector` — выбор дней недели для привычки

#### CRUD привычек
- `openHabitModal(habit)` — открытие модалки создания/редактирования
- `saveHabit()` — сохранение привычки (создание или обновление)
- `confirmDeleteHabit(habit)` — подтверждение архивации
- `executeDelete()` — архивация привычки
- `handleReorderSave(newOrderHabits)` — сохранение нового порядка привычек

#### Таймер привычки
- `habitTimer` — состояние таймера
- Запуск/остановка/сохранение результатов таймера
- Сохранение наработанных часов в запись привычки

#### Форма привычки

#### Прогресс и мотивация

- `yearProgress` — данные о прогрессе года

- `quotes[]` — массив мотивационных цитат

#### Управление датами
- `year` / `month` — выбранный год и месяц
- `setShowDateModal(true)` — открытие выбора месяца
- `MonthPickerModal` — модалка выбора месяца

#### Туториал
- `useTutorial('habits')` — хук туториала для привычек
- `HabitsTutorial` — компонент туториала

- `changeMonth(dir)` — переключение месяца
- `changeWeek(dir)` — переключение недели

- `renderCell(d, m, y)` — рендер ячейки дня
- `renderMonthGrid()` — отрисовка сетки месяца
- `renderWeekStrip()` — отрисовка полосы недели
- `viewMode` — режим просмотра (month/week)
- `selectedDay` — выбранный день

#### Барабанный выбор даты
- `InfiniteWheel` — бесконечно скроллящийся барабан для выбора
- `DateDrumPicker` — модалка с барабанами для выбора даты
- Выбор дня/месяца/года отдельными барабанами

#### Привычки в календаре
- `getActiveHabitsForDay(habits, day, month0, year)` — активные привычки для дня
- `HOLIDAYS_2026` — праздничные дни

#### Туториал
- `useTutorial('calendar')` — хук туториала
- `CalendarTutorial` — компонент туториала
- `restartTutorial()` — перезапуск обучения

## 11. AppLockScreen.js — Экран блокировки

### Основное назначение
Защита входа в приложение по PIN-коду или биометрии (отпечаток/лицо).

### Функции:

#### Биометрия
- `tryBiometric()` — попытка биометрической аутентификации
- `bioAvailable` — доступность биометрии на устройстве
- `bioEnabled` — включена ли биометрия в настройках
- `isBiometricUnlockEnabled()` — проверка настройки
- Автоматический запуск биометрии при открытии экрана

#### PIN-код
- `onKey(key)` — обработка нажатия клавиши (0-9, back, bio)
- `submit(value)` — проверка PIN-кода
- `verifyPin(value)` — верификация через secure storage
- `pin` — введенный PIN
- `pinLength` — длина PIN (4-6 цифр)
- `error` — сообщение об ошибке

#### Клавиатура
- `KEYS[]` — раскладка клавиатуры (1-9, bio, 0, back)
- `Vibration.vibrate(80)` — вибрация при ошибке
- Визуальное отображение точек для введенных цифр

#### Разблокировка
- `onUnlock` — колбэк успешной разблокировки
- Автоматическая проверка при достижении длины PIN
