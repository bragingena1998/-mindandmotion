# AI_CONTEXT.md — MindAndMotion

## Стиль работы с AI

### Как мы работаем
- Вся разработка ведётся через AI-чат (Perplexity, Claude, GPT)
- AI читает актуальный код напрямую из GitHub ветки `mobile-dev3.0`
- Репозиторий: `bragingena1998/-mindandmotion`
- После каждого изменения код пушится на GitHub, AI читает свежую версию
- Исправления передаются через **готовые промты** для вставки в другой чат

### Формат запросов
- Описываем симптом + ожидаемое поведение
- AI анализирует реальный код из репо, не угадывает
- Получаем конкретные промты с готовым кодом
- Не просим "объясни" — просим "дай промт для чата"

---

## Стек

- **Frontend**: React Native (Expo), файловый роутинг через `app/`
- **Backend**: Node.js / Express, `var/www/backend/`
- **Хранилище**: JSON-файлы на сервере (задачи, привычки, настройки)
- **Синхронизация**: REST API, POST `/api/habits/sync`, POST `/api/tasks/sync`
- **Платформа**: Android (основная), iOS (вторичная)

---

## Архитектура данных

### Привычки
- Хранятся в `habitsData` — массив объектов
- Данные ячеек: `cellData[habitId][year][month][day]`
- Тип ячейки: `checkbox`, `counter`, `hours` (таймер)
- Синхронизация через `saveHabits()` → POST `/api/habits/sync`

### Задачи  
- Хранятся в `tasksData` — массив объектов
- Синхронизация через `saveTasks()` → POST `/api/tasks/sync`
- Дебаунс 600ms через `debouncedSave(immediate?)`

## Правила для AI

1. **Всегда читай актуальный код** из ветки `mobile-dev3.0` перед ответом
2. **Давай готовые промты** — не объяснения, а код для вставки
3. **Не трогай то что работает** — только указанные функции
4. **Показывай функции целиком** после изменений
5. **Проверяй порядок операций** — особенно в async функциях с setState
6. Если нужна структура данных — спроси, не угадывай
