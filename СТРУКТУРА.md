# MIND & MOTION — СТРУКТУРА И ТЕХНИЧЕСКОЕ ОПИСАНИЕ UI

Документ содержит детальное техническое описание графической составляющей экранов: структура, компоненты, кнопки, модалки, стилизация.

## 1. TASKS SCREEN — Экран задач

### Контейнерная структура
```
<Background>                    // Градиентный фон
  └─ <GestureHandlerRootView>   // Обработка жестов
      └─ <View style={styles.container}>
          ├─ HEADER            // Шапка с заголовком
          ├─ FOCUS BANNER      // Баннер активной фокус-сессии (условно)
          ├─ DRAG HINT         // Подсказка при drag (условно)
          ├─ STATS             // Карточки статистики
          ├─ FILTER CHIPS    // Чипы фильтрации
          ├─ FOLDERS         // Горизонтальный скролл папок
          ├─ TASK LIST       // SectionList задач
          └─ FAB             // Плавающая кнопка +
      └─ DRAG GHOST          // Призрак перетаскиваемой задачи (условно)
  └─ TOAST                   // Всплывающее уведомление
  └─ MODALS (все модалки)    // Портальные модальные окна
  └─ TUTORIAL OVERLAY        // Оверлей обучения
```

### ШАПКА (HEADER)
**Компонент:** `<View style={styles.header}>`
- **Контейнер:** `flexDirection: 'row'`, `justifyContent: 'space-between'`, `paddingHorizontal: 20`, `paddingVertical: 16`
- **Фон:** `colors.surface` с нижней границей `borderBottomWidth: 1`, `borderBottomColor: 'rgba(148,163,184,0.25)'`

**Элементы:**
1. **Заголовок "МОИ ЗАДАЧИ"**
   - `<Text>` с `fontSize: 18`, `fontWeight: 'bold'`, `letterSpacing: 0.12`, `textTransform: 'uppercase'`
   - Цвет: `colors.accentText`

2. **Выбор месяца (справа)**
   - `<TouchableOpacity>` с `flexDirection: 'row'`, `alignItems: 'center'`, `gap: 4`
   - Текст месяца в формате "МАРТ 2026" — `toLocaleString('ru-RU', { month: 'long', year: 'numeric' }).toUpperCase()`
   - Стрелка вниз: `<Text>▼</Text>` с `fontSize: 12`, `color: colors.textMuted`
   - Действие: `setShowMonthPicker(true)`

### БАННЕР ФОКУС-СЕССИИ (условный)
**Показывается:** когда `focusTask && !focusVisible`
- **Контейнер:** `<TouchableOpacity style={styles.focusBanner}>`
- **Стили:** `paddingHorizontal: 16`, `paddingVertical: 10`, `marginHorizontal: 16`, `marginTop: 8`, `borderRadius: 10`
- **Фон:** `colors.accent1` (акцентный цвет темы)
- **Текст:** `"🎯 Идёт фокус-сессия: {focusTask.title}"`
- **Цвет текста:** `'#020617'` (тёмный для контраста)
- **Действие:** `onPress={() => setFocusVisible(true)}` — разворачивает модалку таймера

### ПОДСКАЗКА ПЕРЕТАСКИВАНИЯ (DRAG HINT)
**Показывается:** когда `dragTask` (активен режим drag)
- **Контейнер:** `<View style={styles.dragHint}>`
- **Стили:** `marginHorizontal: 16`, `marginTop: 8`, `marginBottom: 4`, `paddingVertical: 8`, `paddingHorizontal: 12`, `borderRadius: 10`, `borderWidth: 1`
- **Фон:** `colors.accent1 + '22'` (полупрозрачный акцент)
- **Граница:** `borderColor: colors.accent1`
- **Текст:** `"📂 Перетащи в папку ниже или отпусти для отмены"`
- **Выравнивание:** `textAlign: 'center'`, `fontSize: 12`, `fontWeight: '700'`

### СТАТИСТИКА (STATS)
**Показывается:** когда `!dragTask`
- **Контейнер:** `<View style={styles.statsContainer}>` — `flexDirection: 'row'`, `paddingHorizontal: 16`, `paddingTop: 12`, `paddingBottom: 8`, `gap: 8`

**4 карточки статистики:**
```javascript

  { n: `${stats.today}/${stats.todayPlan}`, l: 'СЕГОДНЯ' },
  { n: stats.week, l: 'НЕДЕЛЯ' },
  { n: stats.month, l: 'МЕСЯЦ' },

```

**Карточка:**
- `flex: 1`, `padding: 12`, `borderRadius: 12`, `borderWidth: 1`
- **Фон:** `colors.surface`
- **Граница:** `colors.accentBorder`
- **Тень:** `elevation: 4`
- **Число:** `fontSize: 28`, `fontWeight: '700`, `color: colors.accentText`
- **Лейбл:** `fontSize: 10`, `textTransform: 'uppercase'`, `letterSpacing: 0.08`, `color: colors.textMuted`

### ЧИПЫ ФИЛЬТРАЦИИ (FILTER CHIPS)
**Показываются:** когда `!dragTask`
- **Контейнер:** `<View style={styles.chipsContainer}>` — `flexDirection: 'row'`, `gap: 8`, `paddingHorizontal: 16`, `paddingTop: 4`, `paddingBottom: 4`

**Чип 1 — "Скрыты ✅" / "Все задачи"**
- `<TouchableOpacity style={styles.chip}>`
- **Размеры:** `paddingHorizontal: 12`, `paddingVertical: 8`, `borderRadius: 20`, `borderWidth: 1`
- **Активный:** `backgroundColor: colors.accent1`, текст `'#020617'`
- **Неактивный:** `backgroundColor: colors.surface`, текст `colors.textMuted`
- **Действие:** `onPress={() => setHideCompleted(!hideCompleted)}`

**Чип 2 — Сортировка**
- Тот же стиль `styles.chip`
- **Содержимое:**
  - `📅 По дате` (sortBy === 'date')
  - `🔥 По важности` (sortBy === 'priority')
  - `abc По имени` (sortBy === 'title')
- **Действие:** циклическое переключение date → priority → title → date

### ПАПКИ (FOLDERS)
**Контейнер:** `<ScrollView horizontal showsHorizontalScrollIndicator={false}>`
- **Стили:** `styles.foldersScrollWrapper` — `flexShrink: 0`, `flexGrow: 0`
- **Контент:** `styles.foldersScroll` — `paddingHorizontal: 16`, `paddingTop: 6`, `paddingBottom: 6`, `gap: 8`, `flexDirection: 'row'`
- **Скролл:** отключается при `dragTask` (`scrollEnabled={!dragTask}`)

**Режимы отображения:**

**A. Обычный режим:**
1. **"📋 Все"** (дефолтный фильтр)
   - Активный: `backgroundColor: colors.accent1`, текст `'#020617'`
   - Неактивный: `backgroundColor: colors.surface`, текст `colors.textMain`

2. **Папки пользователя** (map по `folders`)
   - Чип с `folder.icon` + `folder.name`
   - `onPress` — переключение фильтра
   - `onLongPress` с `delayLongPress={350}` — открытие модалки действий с папкой

3. **"＋ Папка"** (создание)
   - `borderStyle: 'dashed'`
   - Действие: `setShowCreateFolderModal(true)`

**B. Режим Drag & Drop:**
- Рендерится массив `dragFolderList = [{ id: null, icon: '📋', name: 'Без папки' }, ...folders]`
- Используется компонент `FolderDropChip` с:
  - Pulse-анимацией при наведении
  - Измерением координат через `measure`
  - Визуальным выделением `isHovered`

**FolderDropChip стили:**
- `paddingHorizontal: 14`, `paddingVertical: 10`, `borderRadius: 20`, `borderWidth: 2`
- При наведении: `backgroundColor: colors.accent1`, `borderColor: colors.accent1`, `transform: [{ scale }]`, тень

### СПИСОК ЗАДАЧ (TASK LIST)
**Компонент:** `<SectionList>`
- **Стили:** `contentContainerStyle: styles.listContent` — `padding: 16`, `paddingBottom: 100`
- **Секции:** `taskSections` — массив из 4 секций: 'ПРОСРОЧЕННЫЕ', 'СЕГОДНЯ', 'БУДУЩИЕ', 'БЕЗ ДАТЫ'
- **Pull-to-refresh:** `<RefreshControl>` с `tintColor: colors.accent1`
- **Empty state:** сообщение "У вас пока нет задач" / "В этой папке нет задач"

**Заголовок секции:**
```javascript
<View style={styles.sectionHeaderWrap}>
  <Text style={[styles.sectionHeaderText, { color: section.color }]}>
    {section.title}
  </Text>
</View>
// paddingTop: 8, paddingBottom: 10
// fontSize: 12, fontWeight: '800', letterSpacing: 0.8
```

**Заголовок даты (для будущих задач):**
```javascript
<View style={styles.dateHeaderWrap}>
  <Text style={[styles.dateHeaderText, { color: colors.textMuted }]}>
    {item.dateLabel}  // "12 марта"
  </Text>

// marginTop: 4, marginBottom: 8
// fontSize: 12, fontWeight: '600', textTransform: 'uppercase'
```

### КАРТОЧКА ЗАДАЧИ (DraggableTaskItem)
**Основной контейнер:** `<PanGestureHandler>` (обработка drag) → `<Animated.View>` → `<Swipeable>`

**Структура карточки:**
```
<Swipeable>
  └─ <TouchableOpacity style={styles.taskItem}>
      ├─ <View style={styles.checkboxArea}>  // Чекбокс слева
      │   └─ <View style={styles.checkbox}>   // Квадрат 24x24
      │       └─ {completed && <Text>✓</Text>}
      ├─ <View style={styles.taskContent}>   // Основной контент
      │   ├─ <Text style={styles.taskTitle}>   // Название задачи
      │   ├─ <View style={styles.statusBadge}> // Статус: 🔥 ПРОСРОЧЕНО / ⚡ СЕГОДНЯ / 📅 В ПЛАНЕ
      │   └─ <View style={styles.taskMeta}>    // Мета-инфо
      │       ├─ <View style={styles.priorityBadge}> // ВЫСОКИЙ/СРЕДНИЙ/НИЗКИЙ
      │       ├─ <Text style={styles.taskDate}>      // Дата
      │       ├─ {subtasks_count > 0 && <Text>📋 N</Text>}
      │       └─ {folder && <Text>{folder.icon} {folder.name}</Text>}
      ├─ <TouchableOpacity style={styles.editButton}> // ✏️ Справа
      └─ <View>  // ▼ Стрелка разворачивания подзадач
```

**Стили taskItem:**
- `flexDirection: 'row'`, `alignItems: 'center'`, `padding: 16`
- `borderRadius: 12`, `borderWidth: 1`, `marginBottom: 12`
- **Граница (динамическая):**
  - `overdue` → `colors.danger1` (красный)
  - `today` → `colors.ok1` (зелёный)
  - `future` → `colors.borderSubtle` (нейтральный)
  - `completed` → `colors.textMuted` + `opacity: 0.6`

**Свайп-действия:**
- **Влево (LEFT):** Зелёный фон `#4CAF50`, иконка ✓, текст "ГОТОВО" → выполнение задачи
- **Вправо (RIGHT):** Зелёный фон `#22C55E`, иконка 🎯, текст "ФОКУС" → запуск фокус-сессии

**Раскрытые подзадачи:**
- `<View style={styles.subtasksContainer}>` — `marginLeft: 20`, `marginRight: 20`, `marginTop: -8`, `marginBottom: 12`, `padding: 12`, `borderRadius: 8`, `borderWidth: 1`
- **Граница:** `borderColor: 'rgba(148,163,184,0.2)'`

### Цветовая система (из useTheme)
```javascript
colors = {
  background:      // Фон экрана
  surface:         // Фон карточек/панелей
  accent1:         // Основной акцент (кнопки, активные состояния)
  accentText:      // Текст акцента
  accentBorder:    // Граница акцента
  danger1:         // Опасные действия (удаление, просрочка)
  ok1:             // Успешные действия
  textMain:        // Основной текст
  textMuted:       // Вторичный текст
  border:          // Границы
  borderSubtle:    // Лёгкие границы
}
```

### Типографика
- **Заголовки секций:** `fontSize: 12`, `fontWeight: '700'`, `letterSpacing: 1`, `textTransform: 'uppercase'`
- **Основной текст:** `fontSize: 14-16`
- **Мета-информация:** `fontSize: 10-12`
- **Большие числа:** `fontSize: 28-32`, `fontWeight: '700'`

### Размеры компонентов
