# Telegram Intake Format

> Стандарт структурированного сообщения, которое Telegram intake-бот возвращает тебе после приёма голоса или текста.
> Этот блок ты копируешь и отправляешь в Perplexity для получения Windsurf-ready prompt.

---

## Формат блока [INTAKE]

```
[INTAKE]
Текст: <исходный текст или транскрипт голоса>
Проблема: <одной фразой — что именно сломано или нужно сделать>
Гипотеза: <предполагаемая причина или подход>
Зона: web | backend | mobile | docs
Файлы вероятно: <список файлов или компонентов, если известно>
Риск: low | medium | high
Нужен prompt для Windsurf: yes | no
[/INTAKE]
```

---

## Пример: баг

```
[INTAKE]
Текст: На странице привычек дублируются записи после обновления страницы
Проблема: HabitRecord создаётся дважды при рефреше
Гипотеза: useEffect срабатывает дважды в StrictMode или race condition в POST /habits/records
Зона: web
Файлы вероятно: apps/web/src/pages/HabitsPage.jsx, apps/web/src/api/habits.js
Риск: medium
Нужен prompt для Windsurf: yes
[/INTAKE]
```

## Пример: новая фича

```
[INTAKE]
Текст: Хочу добавить кнопку "Перенести задачу на завтра" прямо в списке
Проблема: нет быстрого способа переноса задачи без открытия детального вида
Гипотеза: swipe-action или контекстное меню на элементе списка
Зона: mobile
Файлы вероятно: mindandmotion-mobile/src/screens/TasksScreen.js
Риск: low
Нужен prompt для Windsurf: yes
[/INTAKE]
```

---

## Правила заполнения

- **Текст** — дословный транскрипт или вводный текст, без правки
- **Проблема** — максимум одно предложение, без воды
- **Гипотеза** — не обязательна, если не знаешь — пиши `неизвестно`
- **Зона** — выбирай одну: `web`, `backend`, `mobile`, `docs`
- **Файлы** — если не знаешь — пиши `неизвестно`
- **Риск** — `low` = косметика, `medium` = логика/данные, `high` = auth/deploy/DB
- **Нужен prompt** — `yes` если надо отправить Windsurf, `no` если просто анализ
