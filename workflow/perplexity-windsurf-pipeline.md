# Workflow: Perplexity → Windsurf Pipeline

> Как правильно работать с двумя AI-агентами вместе

## Схема работы

```
Ты (голосом в ТГ или текстом)
         ↓
  транскрипция / сообщение
         ↓
┌────────────────────────────────────────┐
│         PERPLEXITY (анализ)            │
│  • отвечает на вопросы                 │
│  • анализирует архитектуру             │
│  • пишет промпты для Windsurf          │
│  • помогает с документацией            │
│  • объясняет ошибки                    │
└────────────────────────────────────────┘
         ↓  (готовый промпт)
┌────────────────────────────────────────┐
│         WINDSURF (реализация)          │
│  • читает код                          │
│  • делает изменения в файлах           │
│  • запускает команды в терминале       │
│  • обновляет документацию              │
└────────────────────────────────────────┘
         ↓
  git push → Telegram апрув
         ↓
      деплой
```

## Правило разделения ролей

| Вопрос | Кому задавать |
|---|---|
| Почему так устроено? | Perplexity |
| Что лучше выбрать? | Perplexity |
| Как реализовать фичу? | Perplexity → даёт промпт → Windsurf |
| Сделай конкретное изменение в коде | Windsurf напрямую |
| Объясни эту ошибку | Perplexity |
| Дебаг конкретного файла | Windsurf |
| Архитектурные решения | Perplexity |
| Рефакторинг конкретного компонента | Windsurf |

## Три режима использования

### Режим 1 — Быстрая правка (только Windsurf)
Если задача маленькая и понятная:
```
Ты → Windsurf напрямую
"Исправь баг в TaskCard.tsx — при клике на чекбокс страница скроллится вверх"
```

### Режим 2 — Сложная задача (Perplexity → Windsurf)
Если нужен анализ, архитектура или промпт:
```
1. Ты описываешь задачу Perplexity
2. Perplexity анализирует и даёт готовый промпт
3. Ты копируешь промпт → вставляешь в Windsurf
4. Windsurf делает изменения
5. git push через safe-скрипт
```

### Режим 3 — Планирование (только Perplexity)
Если нужно решить что делать:
```
"Я хочу добавить виджет статистики на главный экран.
Что лучше — отдельный компонент или расширить существующий?"
```
Perplexity отвечает, ты принимаешь решение, потом идёшь в Windsurf.

## Шаблон запроса к Perplexity для получения промпта Windsurf

```
Мне нужен промпт для Windsurf.
Задача: [что нужно сделать]
Контекст: [какой файл/компонент/экран]
Ограничения: [что нельзя трогать]
Стек: [React/RN/Node]
```

## Шаблон промпта для Windsurf (стандартный)

Perplexity обычно даёт промпт в таком формате:

```
Прочитай сначала:
- AGENTS.md (структура и правила)
- [конкретные файлы]

Задача: [описание]

План:
1. [шаг 1]
2. [шаг 2]

Ограничения:
- [не трогать X]
- [сохранить поведение Y]

После выполнения:
- Обновить docs/STATUS.md
- Создать docs/handoffs/YYYY-MM-DD_название.md
```

## Голосовой workflow (через Telegram)

```
1. Надиктовал голос в ТГ
2. Транскрипция → прочитал текст
3. Если простая правка → скопировал в Windsurf
4. Если сложная задача → отправил Perplexity, получил промпт
5. Промпт → Windsurf
6. Windsurf сделал изменения
7. .\scripts\git-push-safe.ps1 "описание" → апрув в ТГ
8. При необходимости: .\scripts\safe-deploy.ps1 -Target backend
```
