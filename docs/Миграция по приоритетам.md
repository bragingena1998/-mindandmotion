## Фаза 1: Scaffold + Core (Неделя 1)

### День 1-2: Создание проекта и инфраструктура

**Создаваемые файлы:**

| Файл | Назначение | Содержимое |
|------|------------|------------|
| `apps/web/package.json` | Зависимости | React 18, Vite, React Router, Axios, date-fns |
| `apps/web/vite.config.ts` | Vite config | Port 3001, proxy для API, build outDir: 'dist' |
| `apps/web/.env` | API URL | `VITE_API_URL=http://localhost:5000/api` |
| `apps/web/.env.production` | Prod API | `VITE_API_URL=https://mindandmotion.ru/api` |
| `apps/web/index.html` | Entry point | Root div + viewport meta для mobile |

**Устанавливаемые зависимости:**
```bash
npm install react react-dom react-router-dom axios date-fns lucide-react
npm install -D @types/react @types/react-dom @vitejs/plugin-react typescript
```

### День 3-4: Стили и тема (из habits-app)

**Создаваемые файлы:**

| Файл | Источник | Что переносим |
|------|----------|---------------|
| `apps/web/src/styles/variables.css` | `habits-app/common.css` | CSS переменные: `--bg-primary`, `--accent-color`, etc. |
| `apps/web/src/styles/global.css` | `habits-app/common.css` | Reset, base styles, scrollbar |
| `apps/web/src/styles/components.css` | `habits-app/habits.css` + `tasks.css` | Классы для таблиц, карточек, кнопок |


### День 5-7: API клиент и Auth

**Создаваемые файлы:**

| Файл | Назначение | Логика |
|------|------------|--------|
| `apps/web/src/api/client.ts` | Axios instance | Base URL из `import.meta.env.VITE_API_URL`, interceptors для token |
| `apps/web/src/api/auth.ts` | Auth API | login, register, forgotPassword (из `auth.js`) |
| `apps/web/src/api/tasks.ts` | Tasks API | fetchTasks, createTask, updateTask, deleteTask (из `tasks-api.js`) |
| `apps/web/src/api/habits.ts` | Habits API | fetchHabits, saveHabitRecord (из `HabitsScreen.js`) |
| `apps/web/src/context/AuthContext.tsx` | Auth state | Token в localStorage, login/logout/checkSession |
| `apps/web/src/hooks/useAuth.ts` | Auth hook | `const { user, login, logout } = useAuth()` |

**Риски:**
- **URL конфликт**: habits-app использует `https://mindandmotion.ru`, нужно согласовать с backend
- **CORS**: Backend должен разрешить `localhost:3001` для разработки

## Фаза 2: Страницы (Неделя 2-3)

### Dashboard Page (Priority 1)

**Файл:** `apps/web/src/pages/Dashboard.tsx`

**Компоненты:**
- Life progress bar (из `index.html:31-55`)
- Year progress bar
- Quick stats: completed today/week/month
- Navigation cards → Tasks, Habits, Calendar, Profile

**Стили:** Адаптируем под desktop grid + mobile stack

### Habits Page (Priority 1)

**Файл:** `apps/web/src/pages/Habits.tsx`

**Компоненты:**
- `HabitsTable.tsx` — HTML table (из `habits-app/index.html:91-136`)
- Month selector dropdown
- "Add habit" button + modal
- Life/Year progress bars (CSS анимация)

**Особенности:**
- Сохраняем горизонтальный скролл для мобильных (как в habits-app)
- Desktop: полная таблица без скролла

### Tasks Page (Priority 1)

**Файл:** `apps/web/src/pages/Tasks.tsx`

**Компоненты:**
- `TaskList.tsx` — список задач (не таблица как в habits-app, а карточки)
- `TaskItem.tsx` — title, date, priority badge, done checkbox
- `FolderChips.tsx` — горизонтальный скролл папок (чипы)
- `FilterBar.tsx` — "Скрыть выполненные", сортировка (дата/приоритет/имя)
- `AddTaskModal.tsx` — форма создания/редактирования

**Стили из habits-app:**
- Чипы папок как `.habits-month-select`
- Карточки задач как `.task-card` из `tasks.css`

### Calendar Page (Priority 1)

**Файл:** `apps/web/src/pages/Calendar.tsx`

**Компоненты:**
- Month grid (CSS grid 7 columns)
- Day cells с индикаторами задач/привычек
- Month navigation (prev/next)

**Библиотека:** `date-fns` для календарной логики

### Profile Page (Priority 1)

**Файл:** `apps/web/src/pages/Profile.tsx`

**Компоненты:**
- User info display
- Settings links (placeholder для будущих настроек)
- Logout button

### SecretChat Page (Priority 1)

**Файл:** `apps/web/src/pages/SecretChat.tsx`

**Компоненты:**
