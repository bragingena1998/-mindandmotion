## 5. Архитектурные несоответствия Web ↔ Mobile

### Критические проблемы

| Проблема | Mobile | Web | Риск |
|----------|--------|-----|------|
| **API URL** | `http://85.198.96.149:5000/api` (`api.js:6`) | `https://mindandmotion.ru` (`tasks-api.js:6`) | 🔴 Разные endpoints — web использует прод, mobile — IP |
| **Token key** | `app-auth-token` (AsyncStorage) | `app-auth-token` или `mm_token` (localStorage) | 🟡 Несогласованная миграция |
| **Data adapters** | Прямое использование API | `adaptTaskFromAPI/adaptTaskForAPI` (`tasks-api.js:253-290`) | 🟡 Дублирование логики преобразования |
| **Offline support** | Полный (SQLite + sync queue) | Отсутствует | 🔴 Web не работает без интернета |
| **State management** | Context + local-first hooks | DOM + inline scripts | 🔴 Нет единой архитектуры |
| **Recurring logic** | Серверная (`tasks.js:369-421`) | Только серверная | 🟢 Совпадает |
| **Habit records** | Optimistic updates (`useLocalFirst.js:136`) | Прямые запросы | 🟡 Разный UX при сохранении |

### Средние проблемы

| Проблема | Mobile | Web |
|----------|--------|-----|
| **Роутинг** | Declarative (React Navigation) | Imperative (HTML pages) |
| **Theming** | Centralized (`ThemeContext.js`, `theme/`) | CSS variables + class toggling |
| **Auth flow** | Screen-based (`LoginScreen.js`) | Modal-based (`auth.js`) |
| **Form validation** | Inline в компонентах | Inline в обработчиках |
| **Error handling** | Interceptors (`api.js:35-47`) | Try-catch в каждой функции |

### Файловая структура
- **Mobile**: Чистая архитектура (screens/components/services/utils)
- **Web**: Плоская структура, смешение логики и UI
- **Backend**: Организовано по функциональности (routes/)

## 6. Итоговая сводка

### Общий codebase
- **База данных**: Единая MySQL схема (все проекты совместимы)
- **API**: Единый REST backend (но разные URL в конфигах)
- **Авторизация**: JWT (совместимая)

### Несовместимости
- **State management**: Разные подходы требуют адаптации
- **Offline**: Mobile имеет слой кэширования, web — нет
- **Нативные функции**: Push, биометрия, SQLite — только mobile
- **URL API**: Требует унификации
