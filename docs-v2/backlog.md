# Бэклог по созданию полной документации

## Процесс

Запустить полное исследование структуры кода и API для каждой из 6 частей проекта:

- backend/ — Node.js + Express + MySQL (все роуты, DB схемы, env vars)
- mobile/ — React Native + Expo (структура навигации, экраны, синхронизация)
- web/ — React + Vite (компоненты, клиентский API, ветка)
- tg-bot/ — Node.js Telegraf (назначение, команды)
- habits-app/ — старый HTML/CSS/JS (архив, почему не используется)
- overview.md — общая карта проекта, связи, ветки

## Шаги

1. **backend.md** — собрать все маршруты из backend/routes/*, структуру БД из initDB.js, env vars из .env (если есть), порт запуска.
2. **mobile.md** — прочитать App.js, AppNavigator.js (если есть), список экранов из src/screens/, как синхронизируется с backend.
3. **web.md** — посмотреть package.json, src/ структуру, роуты из App.tsx, App.tsx, 설정 из vite.config.ts.
4. **tg-bot.md** — посмотреть index.js (или есть ли), package.json, назначение.
5. **habits-app.md** — сказать что это архив и почему не используется (смотреть HTML).
6. **overview.md** — собрать ветки для каждой папки из git branch -a + remote.

## Примечания

- Использовать только реальный код и файлы на диске
- Не брать из старых .md файлов в docs/
- Если что-то не можешь определить точно — пометить как "требует уточнения у автора", не выдумывать
